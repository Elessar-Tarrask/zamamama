# План внедрения

## Принятые решения (дефолты — можно поменять, скажите слово)

| Вопрос | Решение |
|---|---|
| WhatsApp-провайдер | **Wazzup**, тариф Inbox (12 000 ₸/мес), за swappable-адаптером |
| Языки | Автоопределение **RU/KZ/EN**, русский по умолчанию; тексты админа на русском, модель переводит для казахо-/англоязычных клиентов |
| Handoff | Бот ставит диалог на паузу, флаг в панели **+ WhatsApp-алерт на номер Даны** |
| Стиль ответов | **Гибрид**: цены, питчи и FAQ — дословными текстами админа (с эмодзи); LLM пишет только связки (приветствия, уточнения, диалог записи) |
| Панель | React + Vite + TS на Firebase Hosting, Firebase Auth |
| Часовой пояс | `Asia/Almaty` (UTC+5) |

## Про Wazzup: дорого ли?

Нет — это дешёвая часть стека. Тарифы за канал WhatsApp: **Inbox 12 000 ₸/мес** (только ответы, 500 диалогов/мес), **Pro 24 000 ₸/мес** (можно писать первым + транскрибация голосовых), **Max 36 000 ₸/мес** (без лимита диалогов). Официальный WABA через Wazzup — 36 000 ₸/мес + плата Meta за шаблоны. Скидка 10%/20% при оплате за 6/12 мес. Бот только *отвечает* входящим лидам → **Inbox достаточно для старта**; Pro понадобится, если захотим напоминания об экскурсии (писать первым) или голосовые. Долгосрочная самая дешёвая альтернатива — Meta Cloud API напрямую (почти бесплатно), но заметно тяжелее в настройке; адаптер позволяет мигрировать без переписывания бота.

## Про open source: есть ли готовое?

Готового end-to-end проекта под эту связку (Firebase + Azure OpenAI + Wazzup + своя панель с редактируемыми сценариями + LLM-запись в календарь) нет. Платформы типа Typebot/Chatwoot/Botpress навязывают свой хостинг, UI и модель диалога — с ними придётся бороться, чтобы получить точные сценарии Даны и требуемую панель. Своё ядро маленькое (~1,5–2k строк). Переиспользуем на уровне библиотек: `openai` (совместим с Azure), `googleapis`, Firebase SDK. Для self-hosted шлюза в будущем — OSS **Evolution API** или **WAHA** в наш адаптер.

## Этапы

- **M0 — Каркас и документация** *(этот коммит)*: архитектура, план, конфиг Firebase, ядро функций (TypeScript), скелет панели, seed-скрипт с текстами.
- **M1 — Эхо-бот** *(нужны: проект Firebase + ключ Wazzup)*: вебхук в проде, handshake, дедуп, фиксированный ответ через адаптер. ✅ *Проверка: пишем на номер — получаем ответ.*
- **M2 — LLM-мозг**: клиент Azure, сборка промпта из Firestore, 20-секундная склейка, извлечение данных лида, гибридный стиль, handoff + алерт, лог неотвеченных. ✅ *Проверка: полный диалог по сценарию Даны, включая уточняющий вопрос на неоднозначную реплику.*
- **M3 — Календарь**: слоты + бронирование, защита от двойной записи, подтверждения. ✅ *Проверка: событие появляется в расшаренном календаре с правильным временем Алматы.*
- **M4 — Админ-панель**: 6 страниц, auth + claims, ручной перехват, «сделать FAQ». ✅ *Проверка: правим ответ FAQ в панели — следующее сообщение в WhatsApp использует новый текст; ручной ответ из панели ставит бота на паузу.*
- **M5 — Hardening**: лимит на чат, игнор групп, алерты об ошибках, структурные логи, юнит-тесты (слоты, сборка промпта, дедуп), интеграционный тест на эмуляторах, финальный SETUP.md.

Реалистичный срок: **~2 недели** с учётом оборота учёток.

## Что нужно от заказчика (по этапам)

1. **Firebase** *(M1)*: создать проект на console.firebase.google.com, включить тариф **Blaze** (pay-as-you-go — обязателен для исходящих HTTP-вызовов из Functions), сообщить project ID (или дать доступ).
2. **Wazzup** *(M1)*: зарегистрироваться, подключить WhatsApp-номер садика (QR), тариф Inbox; передать **API-ключ** (Настройки → Интеграция по API) и **channelId**.
3. **Azure OpenAI** *(M2)*: endpoint (`https://<resource>.openai.azure.com`), **API-ключ**, имя деплоймента `gpt-5-mini`, версия API.
4. **Google Calendar** *(M3)*: выбрать/создать календарь экскурсий; после M1 я передам email сервисного аккаунта — расшарить календарь на него с правом «Внесение изменений в мероприятия».
5. **Административное** *(M2–M4)*: WhatsApp-номер Даны для алертов; email(ы) админов для входа в панель.
6. **Бизнес-параметры** *(M2)*: подтвердить часы экскурсий (по умолчанию пн–пт 09:00–16:00 внутри рабочего дня 8:00–17:00) и длину слота (60 мин); вычитать и заменить seed-тексты — приветствие, питчи, FAQ (места, где у меня нет точных формулировок Даны, помечены «ЗАПОЛНИТЬ»).

**Передача секретов**: не вставляйте ключи в чат/git. Их кладут в Firebase Secret Manager командой `firebase functions:secrets:set` (точные команды — в `docs/SETUP.md`) либо передают по защищённому каналу.

## Приёмочная проверка (end-to-end)

Локально: эмуляторы Firebase + curl-скрипты с реальными payload'ами вебхука Wazzup; юнит-тесты на математику слотов и сборку промпта. На стейджинге, с тестового номера: приветствие → «2 года» → питч Toddler с точными ценами → FAQ → «хочу во вторник» → бот предлагает реальные свободные слоты → подтверждение → событие в Google Calendar → правим FAQ в панели и переспрашиваем — текст обновился → «позовите человека» — бот замолкает, Дане приходит алерт.
